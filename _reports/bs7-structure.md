## 1. 定理精确陈述

### 1.1 论文层面

**Conjecture 1(等价表述)**:对任意正整数集 D,gcd(D)=1,正则色数
`r(D) = liminf_N r(N,D) ≤ |D|+1`,其中
`r(N,D) = min{κ : ∃λ∈Z_N, |λd|_N ≥ N/κ ∀d∈D}`,
`|x|_N` = x mod N 到 0 的循环距离(min(res, N−res))。

**本文证明 `|D| = 6` 时 r(D) ≤ 7**(七名跑者:1 静止 + 6 动)。
实际证明给出乘子存在性 "∃λ,M: |λd|_M ≥ M/7 ∀d",t = λ/M 即孤独时刻。
λ **不必是 Z_M 单位**(§7 用到 λ=7 mod 98 这类非单位乘子)。

### 1.2 冻结声明(Lean,逐符号镜像 lrc6)

```lean
theorem lrc7_int (D : Finset ℕ) (hpos : ∀ d ∈ D, 0 < d)
    (hcard : D.card ≤ 6) :
    ∃ t : ℝ, 0 < t ∧ ∀ d ∈ D, (1 / 7 : ℝ) ≤ circ (t * d)

theorem lrc7_rel_rat (w : Fin 6 → ℚ) (hw : ∀ i, w i ≠ 0) :
    ∃ t : ℝ, 0 < t ∧ ∀ i, (1 / 7 : ℝ) ≤ circ (t * (w i : ℝ))

theorem lonely_runner_seven_rat (v : Fin 7 → ℚ)
    (hv : Function.Injective v) :
    ∀ i : Fin 7, ∃ t : ℝ, 0 ≤ t ∧ ∀ j : Fin 7, j ≠ i →
      (1 / 7 : ℝ) ≤ dist ((t * (v i : ℝ) : UnitAddCircle) : UnitAddCircle)
        ((t * (v j : ℝ) : UnitAddCircle) : UnitAddCircle)
```

形式化锚点(google-deepmind/formal-conjectures `LonelyRunnerConjecture.lean`):
Fin n ↪ ℝ 两两不同速度、UnitAddCircle dist ≥ 1/n、∃t≥0 —— 语义一致
(Function.Injective 与 embedding 对有限索引等价)。

## 3. Prime Filtering 对应关系(确认)

`Research07/LRC5/Filtering.lean` 的 `filtered_multiplier` **正是论文
Lemma 2 + Corollary 3 的 p=5 实例化**,两处特化:

1. p 写死为 5(ZMod 5、padicValNat 5、5^{m−j});
2. 禁集统一为 {0, p−1}(LRC5 只需 Corollary 3 形式)。

n=7 需要 **p=7 的完整 Lemma 2**:

- 建议 `{p : ℕ} (hp : p.Prime)` 泛化或 p=7 克隆(克隆优先,严禁动 LRC5);
- **逐元素禁集** `F : ℕ → Finset (ZMod 7)`,层级条件:
  `Σ_{d∈level j} |F_d| ≤ 6`(j<m);顶层 `Σ ≤ 5`(Λ_m 只有 6 个单位);
- 实际用法多为"单元素精确置位":F_d = Z_7∖{c}(|F|=6)把 q(λd) 钉到 c;
- 顶层归一化(e = N/7 或 e = kN/7)是 Λ_m 标量,单独小引理;
- Lemma 9(i) 这类用法把 Lemma 2 作用于**差分集** B−B(与 D 不同的集合)——
  接口必须允许任意正整数集,乘子随后作用于整个构型。

注意:Lemma 2 证明的顺序是**先顶层 Λ_m 再下行** Λ_{m−1}…Λ₀;
Λ_j(j<m)保持所有 ν>j 元素剩余 verbatim,故复合顺序安全。

## 4. 外层二分法(§4 Overview)

设 D,|D|≤6,全正。m = max ν₇(D),N = 7^{m+1}。

**预处理**:全体被 7 整除 ⇒ D↦D/7,m↦m−1,对 m 强递归。
终止时 D_7(0)≠∅(只需"非全被 7 整除",不要求 gcd(D)=1;
|7^a·x|_{7^{a+b}} = 7^a·|x|_{7^b} 缩放引理负责提升)。

**符号翻转**:d∈D_7(0) 换成 N−d(|·|_N 不变、ν=0 保持、r 反号)。
WLOG (A)_7 ⊆ {1,2,4},A := D_7(0)。

**m=0**:所有元素单位 mod 7,λ=1:|d|_7 ≥ 1 = N/7。✓

**情形树**(D_7(0)≠∅,m≥1):

- 所有层 j<m 满足 |D_7(j)| ≤ 3 ⇒ Cor 3(F={0,6},2·|level|≤6)⇒ 完成。
- 否则唯一一层 |D_7(j₀)| ∈ {4,5}(|D|≤6 ⇒ 至多一个这样的层):
  - **j₀ > 0**(⇒ 恰 =4;余 2 元素在层 0、层 m):
    D' = {d/7^{j₀} : d∈D∖D_7(0)}(4 单位 + 1 顶层,m'=m−j₀<m)。
    递归解 D' → λ' 提升回 N → 对层 <j₀ 用 Λ_{<j₀} 过滤(低层元素总数 ≤1)。
  - **j₀ = 0,|A| = 4**:§5(余 2 元素:层 i₀∈(0,m] + 层 m,或都在层 m;顶层自动好)。
  - **j₀ = 0,|A| = 5**:余 1 元素必在层 m(自动好)。m>1 → §6;m=1 → §7。

## 5. §5:|A| = 4 结构

A={d1..d4}⊂D_7(0),d5∈D_7(i₀)(0<i₀≤m),d5 = u·7^{i₀},
u'·u ≡ 1 (mod 7^{m+1−i₀})。特殊乘子族:

```
Λ' = { λ'_j = j·u'·(1+7^{m−i₀}) : 1≤j≤5 }   eq.8: |λ'_j d5|_N = j(7^m+7^{i₀}) ≥ N/7
Λ₀ = { λ_k = 1+k·7^m : 0≤k≤6 }              保 d5 剩余 verbatim(ν(d5)>0)
```

动力学(eq.9,10):q(λ'_{j+1}d) ∈ q(λ'_j d)+q(λ'_1 d)+{0,1};
q(λ_k d) = q(d)+k·r(d)。目标:∃λ'∈Λ',λ∈Λ₀: q(λλ'A)∩{0,6}=∅。

按最大同余类 |A_s|(s∈{1,2,4})三案,均为 **Z_7 有限推理**:

- **|A_s|=4**:某 λ' 使 ℓ(λ'A)≤5 ⇒ Λ₀ 平移收尾(长-5 AP 的补集是 2 个循环相邻点,
  {0,6} 循环相邻 ⇒ 存在避开平移)。否则 WLOG q(λ'_1A)={0,2,4,6},
  eq.9 推进 j=3,4 得矛盾。
- **|A_s|=3**:ℓ(λ'A_s)≤4 ⇒ 两个候选 k 之一把 d4 送出 {0,6}。
  否则 q(λ'_1A_s)∈{{0,1,4},{0,2,4}} 两模式,进位推进出矛盾。
- **|A_s|=2**:ℓ(λ'A_s)≤2 ⇒ 4 个候选 k 之一处理 A∖A_s(论文 "routine checking"
  = Z_7 有限检)。否则 q(λ'_1A_s)∈{{0,2},{0,3}},进位链至 j=5 出矛盾。

依赖:只用 eqs (7)(8)(9)(10),不依赖 Lemma 4–12。

## 7. §7:|A| = 5,m = 1(有限枚举,已独立复核)
